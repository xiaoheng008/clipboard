## 可调假设（数值，非产品裁决）

| # | 假设 | 默认值 |
|---|---|---|
| H1 | 剪贴板轮询间隔 | 250 ms |
| H2 | 单条文本进入 FTS 的上限 | 前 256 KB（全文仍完整存储并可复制） |
| H3 | 后台索引任务最大重试 | 3 次，退避 2^n s，之后 failed（诊断可见，可 `--reindex` 重置） |
| H4 | 任务租约 | 120 s（被杀或另一进程持有时过期回收） |
| H5 | 语义结果最低相似度 | 0.18（7B 用真数据校准，铁律 25） |
| H6 | 面板分页 | 每页 60 条；内存中最多保留 600 条 |
| H7 | 日志 | 单文件 5 MB × 3 份滚动，不记录剪贴板内容 |
| H8 | 硬件推荐 | 内存 < 16 GB → S0；16–31 GB → S2；≥ 32 GB → B (LT) |
