# Phase 2 — 数据契约

> 契约：下方 DDL 与 `Sources/ClipCore/Storage/Schema.swift` 的 `Schema.v1` **逐字一致**，由测试
> `SchemaDocTests` 比对，任一边改动而另一边没改，测试就失败。版本号存 `PRAGMA user_version`，只前向迁移（C5）。

## 存储 schema v1

<!-- schema:v1:begin -->
```sql
-- 键值配置：hotkey（"keyCode:modifiers"，"none" = 用户已清除）、active_model（图片模型）、
-- active_text_model（文本模型）、excluded_apps（不记录的 App，JSON 数组）
CREATE TABLE settings(
  key   TEXT PRIMARY KEY,   -- 配置名
  value TEXT NOT NULL       -- 配置值（字符串 / JSON）
);

-- 剪贴板历史条目：每条复制内容一行，本地唯一真相
CREATE TABLE items(
  id            INTEGER PRIMARY KEY,                  -- 条目 ID（自增，不变）
  seq           INTEGER NOT NULL UNIQUE,              -- 最近使用序号：每次复制 / 从历史复制都换成新的最大值；两个全文表的 rowid = seq
  kind          TEXT NOT NULL CHECK (kind IN ('text','rich','url','file','image')),  -- 类型：纯文本 / 富文本 / 链接 / 文件 / 图片
  content_hash  TEXT NOT NULL UNIQUE,                 -- 去重键：sha256(kind ‖ 0x00 ‖ 主内容)，同内容再复制只更新时间和次数
  text          TEXT,                                 -- 文本内容；链接为 URL；文件为路径（换行分隔）；图片为 NULL
  blob_hash     TEXT,                                 -- 图片文件名（blobs/ 下的 sha256）；非图片为 NULL
  byte_size     INTEGER NOT NULL,                     -- 内容字节数（含富文本等附加表示）
  width         INTEGER,                              -- 图片宽（像素）
  height        INTEGER,                              -- 图片高（像素）
  source_bundle TEXT,                                 -- 复制时前台 App 的 Bundle ID
  source_name   TEXT,                                 -- 复制时前台 App 的名称
  created_at    INTEGER NOT NULL,                     -- 首次复制时间（毫秒时间戳）
  last_used_at  INTEGER NOT NULL,                     -- 最近一次复制 / 从历史复制的时间（毫秒，仅显示；排序用 seq）
  use_count     INTEGER NOT NULL DEFAULT 1,           -- 复制次数
  pinned        INTEGER NOT NULL DEFAULT 0,           -- 是否置顶（1 = 置顶，排在最前）
  ocr_text      TEXT,                                 -- 图片中识别出的文字；'' = 已识别但无文字，NULL = 尚未识别
  labels        TEXT,                                 -- 图片场景标签（空格分隔的英文词）；NULL = 尚未识别
  fts_truncated INTEGER NOT NULL DEFAULT 0            -- 文本超过 256 KB，全文索引只覆盖前 256 KB（1 = 已截断）
);
CREATE INDEX items_recent ON items(pinned DESC, seq DESC);              -- 浏览列表：置顶在前，最近使用在前
CREATE INDEX items_kind_recent ON items(kind, pinned DESC, seq DESC);   -- 按类型筛选的浏览列表
CREATE INDEX items_blob ON items(blob_hash) WHERE blob_hash IS NOT NULL; -- 删除 / 垃圾回收时查图片文件是否仍被引用

-- 条目的其它剪贴板表示，用于原样写回（富文本的 RTF / HTML、文件的 file-url 列表）
CREATE TABLE representations(
  item_id INTEGER NOT NULL REFERENCES items(id) ON DELETE CASCADE,  -- 所属条目
  uti     TEXT NOT NULL,                                            -- 剪贴板类型（如 public.rtf）
  data    BLOB NOT NULL,                                            -- 该类型的原始数据
  PRIMARY KEY(item_id, uti)
);

-- 全文索引（≥3 字查询，trigram 分词，中英文子串都能命中）。rowid = items.seq，按最近使用流式读取
-- 正文 = 文本（前 256 KB）+ 图中文字 + 图片标签；不存原文（contentless），删除时物理清除
CREATE VIRTUAL TABLE items_fts USING fts5(body, tokenize='trigram', content='', contentless_delete=1);
-- 短词索引（1–2 字查询）：每个词的单字 + 双字（UTF-8 十六进制编码），覆盖每条前 2048 字。rowid = items.seq
CREATE VIRTUAL TABLE items_ngram USING fts5(body, tokenize='ascii', content='', contentless_delete=1, detail='none');

-- 后台索引任务（OCR、生成向量）：与条目同事务入队，成功即删除该行
CREATE TABLE index_jobs(
  id          INTEGER PRIMARY KEY,                                         -- 任务 ID
  item_id     INTEGER NOT NULL REFERENCES items(id) ON DELETE CASCADE,     -- 要处理的条目（条目删除则任务一起删除）
  kind        TEXT NOT NULL CHECK (kind IN ('vision','embed')),            -- vision = OCR + 标签；embed = 生成向量
  model_id    TEXT NOT NULL DEFAULT '',                                    -- embed 任务用的模型；vision 为空
  state       TEXT NOT NULL CHECK (state IN ('pending','running','failed')),  -- 等待 / 执行中 / 重试用尽失败
  attempts    INTEGER NOT NULL DEFAULT 0,                                  -- 已失败次数（达到上限进入 failed）
  not_before  INTEGER NOT NULL DEFAULT 0,                                  -- 退避：此时间（毫秒）之前不执行
  lease_until INTEGER NOT NULL DEFAULT 0,                                  -- 执行租约到期时间（毫秒）；过期可被重新认领，完成 / 失败需租约仍属于自己
  last_error  TEXT,                                                        -- 最近一次失败原因（不含剪贴板内容）
  UNIQUE(item_id, kind, model_id)
);
CREATE INDEX index_jobs_claim ON index_jobs(state, not_before);  -- 认领可执行任务

-- 语义向量：每个（条目, 模型）一行；切换模型时旧模型的向量保留
CREATE TABLE embeddings(
  item_id  INTEGER NOT NULL REFERENCES items(id) ON DELETE CASCADE,  -- 所属条目
  model_id TEXT NOT NULL,                                            -- 生成该向量的模型（含版本，如 siglip2-base@1）
  dim      INTEGER NOT NULL,                                         -- 向量维度
  vec      BLOB NOT NULL,                                            -- 向量：fp16 小端，L2 归一化
  PRIMARY KEY(item_id, model_id)
);
CREATE INDEX embeddings_model ON embeddings(model_id);  -- 按模型加载向量 / 统计覆盖率

```
<!-- schema:v1:end -->

### 字段与表说明

| 表 / 字段 | 含义 |
|---|---|
| `settings` | 键值配置：`hotkey`（`keyCode:modifiers`，`none` = 用户清除）、`active_model`（图片槽）、`active_text_model`（文本槽）、`excluded_apps`（JSON 数组） |
| `items.seq` | **最近使用序号**：每次复制 / 从历史复制都换成新的 `max(seq)+1`；两个全文表的 rowid = `seq`，所以搜索能按新→旧顺序流式读取并在 LIMIT 处停止 |
| `items.content_hash` | `sha256(kind ‖ 0x00 ‖ 主内容)`，去重键（Q1：重复复制 = touch，不新增） |
| `items.text` | 纯文本 / URL / 文件路径（换行分隔）；图片为 NULL |
| `items.blob_hash` | 图片在 `blobs/` 下的 sha256 文件名 |
| `items.ocr_text` / `labels` | vision 任务写入；`''` = 处理过但无结果，NULL = 未处理（reindex 依赖此区分） |
| `items.fts_truncated` | 文本超过 256 KB，只索引前 256 KB（H2） |
| `items.last_used_at` / `created_at` | 毫秒时间戳，仅用于显示；排序用 `seq` |
| `representations` | 富文本 RTF/HTML、文件 URL 列表，用于原样写回剪贴板 |
| `items_fts` | trigram 全文索引（≥3 字查询）；正文 = 文本（截断）+ OCR + 标签；**不含来源 App**（R21：避免搜 “code” 命中所有 VS Code 内容） |
| `items_ngram` | 1–2 字查询索引：每个词的单字 + 双字（UTF-8 十六进制编码），覆盖每条前 2048 字（H9） |
| `index_jobs` | 后台任务（本地 Outbox）：成功即删除；`lease_until` 是认领租约，完成 / 失败只在租约仍属于自己时生效（R12） |
| `embeddings` | 每个 (条目, 模型) 一行，fp16 小端、L2 归一化 |

### 每个连接的设置

`journal_mode=WAL`（写连接）、`foreign_keys=ON`、`synchronous=NORMAL`、`temp_store=MEMORY`、`busy_timeout=5000`、
**`secure_delete=ON`**；两个 FTS 表开启 **`secure-delete`**；删除后 `wal_checkpoint(TRUNCATE)`，清空后 `VACUUM`（R14）。

### 版本与兼容

- `user_version` 高于程序 → 拒绝打开并提示升级（E21，`evidence/7B/diagnose-failure-paths.txt`）。
- `user_version = 1` 但缺 `seq` / `items_ngram`（发布前的旧库）→ 明确报错不兼容（R22）。
- 新版本迁移前用 `VACUUM INTO` 备份为 `clipvault.sqlite.bak-v<n>`。

## 实体契约

### ClipItem（本地权威）

| 维度 | 回答 |
|---|---|
| 身份与权威 | `id` 由 SQLite 分配；`content_hash` 是业务身份（去重）。只有本机用户通过复制、删除、清空修改。无外部裁决者。 |
| 存储与读取 | SQLite `items` + `representations`；图片字节在 `blobs/`。UI 只从 SQLite 分页读（上限 H6），缩略图从 `thumbs/` 懒加载、可重建。内存不持有唯一副本。 |
| 生命周期 | 创建：复制时 ingest。更新：同哈希再复制或从历史复制 → `last_used_at`/`use_count`。删除：单条删除 / 清空（Q4 全部）。无过期（不限历史）。迁移：只前向，迁移前复制库文件到 `clipvault.sqlite.bak-v<n>`。 |
| 「离线」与同步 | 无网络依赖，无同步。 |
| 并发与冲突 | 单写者 actor；跨进程（CLI）靠 SQLite 锁。去重：同一事务内先按 `content_hash` 查，存在则 touch（换新 `seq`、计数 +1），否则插入；`BEGIN IMMEDIATE` 保证跨进程原子。 |
| 一致性 | 不变量 I1–I5 见 `3.1-state-model.md`，由本地事务保证；`--verify` 检测。 |
| 安全 | 单个 macOS 用户的 Library 目录（无账号 → 账号隔离不适用，理由：无登录概念，OS 用户即隔离边界）。Concealed/Transient 不入库（Q2）。日志不写内容。 |
| 失败与证据 | 写库失败：记日志 + 诊断计数，下次变化继续。库损坏：启动诊断 FAIL，提示，不自动删除（本地权威不可重建）。 |

### Blob（本地权威，文件）

| 维度 | 回答 |
|---|---|
| 身份 | sha256(字节)，不可变。 |
| 写入协议 | `tmp/<uuid>` 写入 → `fsync` → `rename` 到 `blobs/ab/<hash>`（已存在则丢弃临时文件）→ **然后**提交 items 事务。 |
| 删除协议 | 提交删除事务 → 若无条目引用该 hash → 删文件与缩略图。死在中间 = 孤儿文件，`--gc` 回收。 |
| 不变量 | I2：每个 `items.blob_hash` 对应的文件存在。孤儿文件允许存在（无害）。 |

### IndexJob（本地权威的进度，等价于 scv-app 的 Outbox）

| 维度 | 回答 |
|---|---|
| 入队 | 与条目同一事务（vision + 当前激活模型的 embed）；激活新模型时为所有缺向量的图片批量入队（事务分批，每批 1000）。 |
| 认领 | 事务内 `pending 且 not_before<=now` 或 `running 且 lease_until<now` → `running, lease_until=now+H4`。 |
| 完成 | 结果写入 + 删除任务行在同一事务；`embeddings` 用 UPSERT（重复处理幂等）。 |
| 失败 | `attempts+1`；`< H3` → `pending, not_before=now+2^attempts s`；否则 `failed` + `last_error`。条目被删 → 级联删除任务（「谁来收尾」：外键）。 |
| 被杀 | `running` 租约过期后被任意执行器重新认领（启动时立即跑一轮）。 |
| 可见性 | 诊断：pending / running / failed 计数；设置页显示语义索引覆盖率。 |

### Embedding（派生）

| 维度 | 回答 |
|---|---|
| 身份 | `(item_id, model_id)`。`model_id` 包含版本（如 `mobileclip-s2@1`），模型文件变了必须换 id。 |
| 存储 | SQLite fp16；内存 `VectorIndex` 只装**激活模型**的向量，可从库重建。 |
| 一致性 | 内存索引与库的差异：启动全量加载；运行中 add/remove 跟随事务提交后调用。诊断比对「库内向量数 = 索引向量数」。 |
| 切换模型 | 旧向量保留（Q5），`--model purge-inactive` 三级阶梯清理。 |

### 模型清单（契约：`Resources/models.json` ↔ `ModelManifest.swift`）

```json
{ "id": "mobileclip-s2@1", "family": "coreml-clip", "displayName": "MobileCLIP S2",
  "tier": 2, "dim": 512, "imageSize": 256, "contextLength": 77,
  "minMemoryGB": 16, "imageInput": "image", "textInput": "text", "output": "final_emb_1",
  "tokenizer": "clip-bpe",
  "files": [ {"path": "image.mlpackage/Manifest.json", "url": "...", "sha256": "...", "size": 617}, ... ] }
```

安装校验：每个文件 sha256 必须匹配，否则删除整个临时目录并报错。安装原子性：下载到 `tmp/model-<uuid>/` → 校验 → 编译 → `rename` 到 `models/<id>/` → 写 `install.json`。目录存在但无 `install.json` = 未安装（启动时清理）。
