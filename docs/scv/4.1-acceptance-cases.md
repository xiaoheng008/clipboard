# Phase 4 — 验收用例

类型：**U** 自动化单测 / **I** 自动化集成（真实系统框架，CLI 驱动）/ **M** 真机手动（证据：截图到 `evidence/`）/ **F** 故障注入。

故障清单选取（verification.md §2）：断网（模型下载）✓、进程终止 ✓、重复提交 ✓、权限撤销 ✓、存储不足（模拟写失败）✓、迁移失败（schema 版本过高）✓、删除与处理并发 ✓。
不选：响应丢失 / 乱序 / 游标过期 / 账号切换 / 多设备冲突——**无服务端、无账号、无同步**，不适用。
