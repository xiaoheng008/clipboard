# Phase 1 — 需求 + 数据分类 + 功能点登记

纯本地应用：**没有服务端、没有网络同步、没有账号**。scv-app 中「服务端确认」「Outbox」在本项目里对应为「**本地事务提交**」与「**本地后台索引任务队列**」：
- 业务事实「已记录」只来自 SQLite 事务提交成功；
- 「已可被 OCR/语义搜到」只来自对应索引任务完成，不得把「已入队」显示成「已索引」（四个分离 2，C19 的本地版）。

唯一的网络行为：用户**显式**点击「下载模型」时从 HuggingFace 下载模型文件。

## 1. 核心场景

| 场景 | 参与者 | 触发 | 正常路径 | 「离线」路径 | 失败路径 | 权限边界 | 重复操作 | 业务不变量 |
|---|---|---|---|---|---|---|---|---|
| S1 记录 | 用户在任意 App 复制 | `NSPasteboard.changeCount` 变化 | 读取表示 → 规范化 → 去重判定 → 一个事务写入条目+FTS+索引任务 | 不涉及网络，始终可用 | 读取被拒/为空 → 不写条目，计数并在诊断显示；写库失败 → 记日志、不丢后续 | 剪贴板隐私授权（F4/A1）；隐藏/临时类型按 Q2 | 同内容再次复制 → 按 Q1 | 条目存在 ⇔ 其内容可读（文本在库 / blob 文件存在） |
| S2 浏览 | 用户 | 全局快捷键 / 菜单栏 | 面板按「最近使用」倒序分页显示 | 同左 | 库打不开 → 面板显示错误 + 诊断入口 | 无 | 重复按快捷键 → 切换显隐 | 列表分页加载，内存有上限（C36） |
| S3 文本搜索 | 用户 | 面板输入 | 输入去抖 → 查询解析 → FTS（含 OCR 文本）→ 结果 | 同左 | 查询语法错 → 退化为字面量搜索 | 无 | 快速连续输入 → 只应用最新一次结果（过期响应丢弃） | 结果只来自已提交数据 |
| S4 语义搜图 | 用户 | 面板输入（图片模式或混合） | 查询（中文先翻译）→ 文本编码 → 向量检索 → 与 S3 融合排序 | 模型未下载 → 只走 S3 并提示「语义搜索未启用」 | 编码失败 → 降级 S3 + 提示 | 翻译语言包（A8） | 同 S3 | 显示「已建语义索引 n / 总图片 m」，不把未索引说成无结果 |
| S5 回贴 | 用户 | 面板中回车/双击 | 写入系统剪贴板 → 关闭面板 → 模拟 ⌘V 到前台 App；更新「最近使用」 | 同左 | 无辅助功能授权 → 只复制并提示「已复制，请手动粘贴」 | 辅助功能（A2） | 双击两次 → 只贴一次（面板已关闭） | 回贴不产生新历史条目（自写剪贴板要被识别并跳过） |
| S6 管理 | 用户 | 面板快捷键/右键 | 置顶、删除、清空（二次确认）| 同左 | 删除事务失败 → 条目保留并提示 | 无 | 重复删除 → 幂等 | 删除后条目、FTS、向量、任务同时消失；blob 无引用后回收 |
| S7 模型管理 | 用户 | 设置页 / CLI `--model install <id>` | 下载 → sha256 校验 → 编译 → 注册 → 激活 → 后台回填向量 | **需要网络**；断网 → 失败可重试，不影响其它功能 | 校验失败 → 删除临时文件、报错；中途被杀 → 重启后临时文件清理、可续/可重下 | 网络 | 重复点击 → 同一模型只一个下载任务 | 激活模型的向量覆盖率可见；切换模型不删旧向量（Q5） |
| S8 自检 | 用户 / 工程师 / 脚本 | 设置页「诊断」/ CLI `--diagnose` | 只读检查，逐项 PASS/FAIL/WARN/SKIP + 观测值；FAIL 非 0 退出 | 同左 | — | 无 | 幂等 | 诊断不修改业务数据 |

## 2. 数据清单（所有业务数据均为**本地权威**；无服务端权威/多方协作）

| 实体 / 派生状态 | 分类 | 所在层 | 可重建？ | 本次覆盖 |
|---|---|---|---|---|
| ClipItem（条目元数据 + 文本内容） | 本地权威 | SQLite | **否**（唯一真相） | ✓ |
| Blob（图片/大载荷，内容寻址文件） | 本地权威 | 文件系统 | **否** | ✓ |
| FTS 索引 | 派生 | SQLite（与条目同库同事务） | 是（从条目 + OCR 文本） | ✓ |
| OCR 文本 | 派生（可重算，但贵） | SQLite | 是（重跑 OCR） | ✓ |
| 图片标签（Vision 分类） | 派生 | SQLite | 是 | ✓ |
| 向量 Embedding（按模型 id 分） | 派生 | SQLite | 是（重跑模型） | ✓ |
| 内存向量索引 | 派生缓存 | 内存（有上限） | 是（从 SQLite 加载） | ✓ |
| 缩略图 | 派生缓存 | 文件系统 | 是 | ✓ |
| IndexJob（后台索引任务） | 本地权威（进度） | SQLite（与条目同事务入队） | 是（对账可补） | ✓ |
| 模型注册表 / 已安装模型 | 本地权威（配置）+ 文件 | JSON manifest + 模型目录 | 可重下 | ✓ |
| 设置（快捷键、激活模型、排除规则） | 本地权威 | SQLite `settings` 表 | 否 | ✓ |
| 面板 UI 状态（查询串、选中项、滚动） | 临时交互 | 内存 | — | ✓ |
| 日志 | 本地 | 滚动文件（有上限，脱敏） | — | ✓ |

类别转换：无（不存在「草稿 → 服务端记录」）。
