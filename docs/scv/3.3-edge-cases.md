# Phase 3 — 边界情况

| # | 情况 | 处置 |
|---|---|---|
| E1 | 复制空字符串 / 只有空白 | 跳过（`SkipReason.empty`） |
| E2 | 同时有 file-url 与文本 | 记为 file（文件优先） |
| E3 | 同时有 RTF/HTML 与纯文本 | 记为 rich，文本用于搜索，RTF/HTML 存 representations 以便原样回写 |
| E4 | 只有图片（png/tiff/jpeg） | image；TIFF 转 PNG 后存（体积）；哈希基于存储字节 |
| E5 | 图片 + 文本同时存在（如 Office） | 文本优先记为 rich/text（与常见剪贴板应用一致）；图片不另存（已知限制） |
| E6 | 超大文本（> 256 KB） | 完整存储；FTS 只索引前 256 KB，`fts_truncated=1` |
| E7 | 超大图片（如 8K 截图 50 MB） | 完整存储；OCR/嵌入用下采样（Vision 自行处理；CLIP 输入 256） |
| E8 | 连续快速复制（< 轮询间隔） | 只能捕获最后一次（平台限制，已知限制） |
| E9 | 从历史复制回剪贴板 | 写入时带 `local.clipvault.self` 类型并记录 changeCount → 识别为自写，只 touch |
| E10 | Concealed / Transient / AutoGenerated 类型 | 跳过，不读取内容 |
| E11 | 前台 App 在排除列表 | 跳过 |
| E12 | 剪贴板访问被拒（alwaysDeny） | 不读取；菜单栏图标标记 + 诊断 FAIL + 设置页提示去系统设置开启 |
| E13 | 进程在 blob 写完、事务前被杀 | 孤儿 blob，gc 回收；条目不存在（不违反 I2） |
| E14 | 进程在 job running 时被杀 | 租约过期重领；结果 UPSERT 幂等 |
| E15 | 删除条目时其 job 正在 running | 级联删除 job；worker 写结果时条目不存在 → 外键失败 → 丢弃结果（不报错为失败） |
| E16 | 模型下载中断 / 校验失败 | 删除 `tmp/model-*`；状态回到「未安装」，可重试 |
| E17 | 激活的模型文件被手动删除 | 启动诊断 FAIL；语义搜索状态「模型不可用」；文本搜索不受影响 |
| E18 | 翻译语言包未安装 | 中文查询直接送 CLIP（效果差）+ 状态条提示「安装中文→英文翻译可提升图片语义搜索」 |
| E19 | 查询含 FTS 特殊字符（`"` `*` `:` `(`） | 规划器把每个词作为带引号的短语，内部 `"` 转义为 `""` |
| E20 | 1–2 字查询 | LIKE `%q%`（`ESCAPE '\\'` 转义 `%` `_`），按最近使用顺序取前 limit |
| E21 | 库 schema 版本高于程序 | 拒绝打开，提示升级，不写库 |
| E22 | 磁盘满 | 事务失败 → 记录 `SkipReason.writeFailed` 计数 + 诊断 FAIL「磁盘空间」|
| E23 | CLI 与 App 同时运行 | WAL + busy_timeout；任务租约防重复 |
| E24 | 面板打开期间新复制 | 浏览态顶部插入；搜索态显示「有新内容」不打乱 |
| E25 | 清空历史期间 worker 在跑 | 级联删 job；worker 写结果遇外键失败丢弃 |
| E26 | 快捷键与系统/他人冲突（注册失败） | 设置页显示「注册失败」，保留旧值 |
