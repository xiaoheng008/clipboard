# Phase 9 — 已知限制（截至 2026-10-17）

交付说明要求把假设、未验证能力、未决事项显式列出。

## 兼容与分发
- 只在 macOS 27.0.1 / Apple M4 / 32 GB 上验证；macOS 15.4–26 为「声明支持、未验证」。
- 系统翻译（中文 → 英文，用于 MobileCLIP）需要 macOS 26+ 且安装语言包；SigLIP2 / E5 不依赖翻译。
- ad-hoc 签名、未公证；每次重新构建后系统剪贴板授权可能需要重新确认。
- schema v1 在发布前修改过一次（加入 `seq` / n-gram 索引），此前的测试库不兼容。

## 搜索质量（真实数据判读，见 `evidence/7B/semantic-judgement-2026-10-17.md`）
- SigLIP2：中英文搜图 top-1 正确率高；纯文字截图之间（聊天 vs 发票）区分弱。
- Multilingual E5 Small：同语言好、英→中可用、**中→英偏弱**；分数集中（0.77–0.91），判据偏严格（floor 0.84），会少返回一些相关结果。计划横向评测 bge-m3 / Qwen3-Embedding。
- 判据（floor / margin）仅基于 14 图 + 14 文本的小样本校准，需要更多真实数据复核。
- 文本向量只覆盖每条内容的前 512 个 token（H10）；1–2 字查询只覆盖前 2048 个字符（H9）。
- 相似图片：图片超出已加载的 600 条或不在当前搜索结果中时，只提示、不定位。

## 验证缺口
- 菜单栏、面板、设置页、快捷键、相似图片定位：尚无截图证据（铁律 26）。
- `.app` 自身的剪贴板授权弹窗行为（A1）未验证；命令行观测到的是终端的授权。
- 故障注入中「进程在 blob 写入后、事务前被杀」只做了单测级模拟，未做真机强杀。
- 100 万条基准在 n-gram / seq 改造后只重跑了 10 万条（全部达标），100 万条未重测。
